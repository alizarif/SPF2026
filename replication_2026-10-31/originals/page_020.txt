formation. Professional forecasters combine several inputs including public macroeconomic
data, prior beliefs, institutional knowledge, and information about the recent consensus. Be-
cause the LLM environment allows us to selectively remove components of the information set,
we can ask which inputs are most important for approximating SPF-like expectations. This
exercise is not intended simply as a prompt ablation. It is an empirical decomposition of the
information sources that allow synthetic agents to approximate professional expectations. We
evaluate the roles of these inputs in shaping expectations by progressively removing them from
the prompt. We run an ablation exercise comparing several “stripped-down” versions of the AI
forecaster to a fully informed benchmark that has access to all three information types.
We begin by simulating expectations for a “generic” forecaster that omits forecaster character-
istics. Prompt 2 illustrates this setup, in which the model relies on real-time data, past median
SPF forecasts, and its pre-trained knowledge. Next, we construct another scenario with the
same generic forecaster but without access to real-time data, shown in Prompt 3. In this case,
the model can only draw on past median SPF forecasts along with its pre-trained knowledge,
thereby mimicking a professional forecaster who lacks timely data releases. Finally, we consider
a setup without any prompt input so that the model only relies on its training data. This setup
is shown in Prompt 4.
Table 8 compares the results of these variants to the baseline results using all information,
see Prompt 1. The table reports MAEs as ratios of baseline MAEs, where values of one indicate
